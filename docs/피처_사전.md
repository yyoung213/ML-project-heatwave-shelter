# 피처 사전 — dong_features_rich.parquet

행정동 256개(폭염 한낮 노출 상위 60퍼센트). 한 행이 한 행정동이다.

## 식별자
| 컬럼 | 의미 |
|---|---|
| k8 | 행정동 코드 8자리 |
| 동명 | 행정동 이름 |
| 자치구 | 소속 자치구 |

## 수요·행동 (매칭 결과에서 산출)
| 컬럼 | 의미 |
|---|---|
| 노출_폭염한낮 | 폭염일 한낮(12-16시) 단기 외국인 도착 규모. 수요의 크기. |
| expo_log | log(1 + 노출_폭염한낮). 군집·모델 입력용 노출 변수. |
| matched_delta | 동별 매칭 회피율(%). 음수=폭염일에 이동을 줄임(회피), 0 근방·양수=거의 안 줄임(비탄력). |
| avoid | matched_delta를 상하위 1퍼센트에서 winsorize 한 값. 군집·모델의 타깃. |
| shift_mid | 폭염일−정상일 한낮 점유율 변화. 양수=냉방 실내(몰)로 옮겨 잔류, 음수=야외 회피. |
| day_ratio | 주간(10-18시) 이동 비율. 관광·업무형일수록 높음. |
| LQ_단기외국인 | 입지계수. 단기 외국인이 평균 대비 얼마나 집중되는가. |
| share_단기 | 동 전체 도착 중 단기 외국인 비중. |

## 공급 (서울 무더위쉼터 4,083개에서 산출)
| 컬럼 | 의미 |
|---|---|
| 쉼터수 | 동 내 전체 무더위쉼터 수. |
| 접근가능수 | 동 내 접근가능 쉼터(공공시설+생활밀착민간) 수. 관광객이 실제 쓸 수 있는 쉼터. |
| 공급_가중 | 유형가중 실효 공급 점수. 공공 1.0·민간 0.8·회원제(경로당) 0.4·야외 0.2를 합산. |
| near_acc_km | 동 중심점에서 가장 가까운 접근가능 쉼터까지의 거리(km). |

## 관광지 (서울 주요 121장소 폴리곤에서 산출)
| 컬럼 | 의미 |
|---|---|
| 관광커버 | 동 면적 중 주요 관광지 폴리곤이 덮는 비율(전체). |
| 야외관광커버 | 야외 관광지(고궁·문화유산·공원) 커버 비율. 폭염 직격 위험. |
| 상업관광커버 | 상업·실내 성격 관광지 커버 비율. |
| 관광지수 | 동에 걸친 관광지 카테고리 수. |

## 지역 특성
| 컬럼 | 의미 |
|---|---|
| 주간인구지수 | 소속 자치구의 주간인구지수. 100보다 크면 주간 유입이 많은 업무 중심지. |

## 참고
- 군집·모델 입력으로 자주 쓰는 핵심 두 축은 expo_log(노출 규모)와 avoid(회피=비탄력)이며, 둘의 상관은 약 +0.09로 거의 독립이다. 곧 어디에 사람이 많은가와 그들이 더위에 얼마나 버티는가는 별개의 정보다.
- 노출이 낮은 동(전체 426개 중 하위 40퍼센트)은 노출 추정이 불안정해 제외했다. 그 동들의 잠재 수요는 이 데이터로 다루지 못한다.
