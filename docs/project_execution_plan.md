# 폭염·미세먼지 취약 외국인 관광객 분석 — 프로젝트 실행 계획서

> 데이터 수집 → 전처리 → EDA → 분석까지 실제 작업 순서로 따라갈 수 있는 실행 문서.
> 주제 배경·선행연구·가설은 별도 팀 공유 문서 참조. 이 문서는 "무엇을, 어떤 순서로, 어떻게 만드는가"에 집중한다.

---

## 0. 프로젝트 개요 (실행 관점 요약)

- **목표 산출물 1 (진단):** 폭염/미세먼지 시 집단별(내국인·단기외국인) 노출 격차 지표 + 취약 핫스팟 지도
- **목표 산출물 2 (운영):** 폭염/고농도 예보일에 외국인이 몰릴 동·시간대 예측 모델
- **분석 단위:** 행정동(약 425개) × 일자 × 시간대(1h)
- **대상 기간:** 코로나 이후 정상 연도 3개 (여름 6~8월 / 미세먼지 축 추가 시 봄 3~5월 병행) — **연도는 D-0 단계에서 확정**
- **핵심 파생 지표:** 노출 격차 `gap = (외국인 실제/외국인 평년) − (내국인 실제/내국인 평년)`

## 2. 전처리 (Phase 2)

### 2.1 공간 키 정리
- 생활인구 = 행정동코드 기준. 기상(B)·미세먼지(C)는 **관측소/측정소 단위** → 행정동에 매핑 필요.
- 매핑 방식: 행정동 중심좌표 기준 **최근접 관측소** 또는 자치구 대표값. 측정소 밀도 낮으면 자치구 단위 보간.
- 행정동코드 체계 연도별 변경(통폐합) 점검 → 기간 내 코드 통일.

### 2.2 시간 키 정리
- 공통 키: `(행정동코드, 일자, 시간대)` 1시간 단위로 정렬.
- 생활인구 시간대구분 코드 → 0~23시 표준화.

### 2.3 결측·비식별 처리
- 생활인구 3명 이하 `*` 마스킹 셀: 결측 플래그 + 0~3 구간 대치 규칙 명시(분석 일관성).
- 기상·미세먼지 관측 결측: 인접 시간 보간 또는 인접 측정소 대체. 보간 여부 플래그 유지.

### 2.4 파생 변수 생성
- **체감온도(열지수):** 기온·습도로 산출(B-1) 또는 B-3 활용.
- **폭염 더미:** 폭염주의보/경보 발효 여부(B-2), 체감온도 임계 구간.
- **미세먼지 등급:** PM2.5 농도·등급(C-1).
- **강수 변수:** 강수량·강수 여부(B-1) — 장마 통제.
- **통제 더미:** 요일, 공휴일(D-1), 월, 성수기, 행사 발생(A-6).

### 2.5 ★ 정규화 및 노출 격차 지표 (분석의 핵심)
- 집단별 원시 체류수를 **"동별 같은 요일·시간대 평년 중앙값 대비 편차" 또는 로그값**으로 변환 → 동 간/집단 간 규모 차이 흡수.
- 노출 격차: `gap = (외국인 실제/외국인 평년) − (내국인 실제/내국인 평년)`
  - 폭염/고농도일에 gap > 0 이고 클수록 "내국인은 빠졌는데 외국인은 남음".

### 2.6 산출물
- `processed/analysis_dataset.parquet` — 분석용 통합 테이블(행: 행정동×일×시간대, 열: 집단별 체류·정규화값·기상·미세먼지·통제·gap)
- 데이터 사전(컬럼 정의·단위·결측규칙) 문서화

## 3. EDA (Phase 3)

> EDA의 1차 목적은 "예쁜 그래프"가 아니라 **분석 가능성 검증**이다. 특히 이벤트 표본이 충분한지부터 본다.

### 3.1 ★ 이벤트 표본 점검 (가장 먼저 — 연도 확정에 직결)
- **연도별 폭염일수**(특보 발효일) 비교 → 강한/평범/약한 여름이 섞였는지 확인. → **D-0 연도 확정 근거.**
- 연도별 단기외국인 총량 → 코로나 회복 수준 확인(급감 연도 제외).
- 미세먼지 축: 연도별 봄철 고농도(PM2.5 '나쁨' 이상) 일수.

### 3.2 집단별 기초 분포
- 내국인·단기외국인·장기외국인 체류의 시간대 패턴(24h), 요일 패턴, 동별 분포.
- 단기외국인 상위 집중 동 식별(명동·이태원·홍대·고궁 등 예상) → 관광 핫스팟 후보.

### 3.3 이벤트 vs 평상 비교(가설 1차 탐색)
- 폭염일 vs 비폭염일에 집단별 체류 변화율 비교(정규화값 기준).
- 동 유형별(실외 관광지 vs 실내 상권) 차이 탐색 → 노출 격차의 공간 이질성 단서.
- 미세먼지 고농도일 동일 비교 → **폭염과 방향이 다른지**(외국인이 미세먼지엔 민감한지) 1차 확인.

### 3.4 교란 요인 점검
- 폭염일과 성수기·주말·행사일 겹침 정도(공선성 위험 진단).
- 체감온도 vs 폭염특보 더미 상관, 폭염 vs 강수 분리 가능성.
- 미세먼지 vs 기온 상관(봄·여름 분리로 완화되는지).

### 3.5 산출물
- EDA 노트북 + 핵심 발견 요약(특히 연도 확정 권고, 가설 1차 지지/반증 여부)

## 4. 분석 계획 (Phase 4)

> 연구 질문은 "외국인은 둔감한가?"(예/아니오)가 아니라 **"노출 격차는 어디서, 얼마나 발생하는가?"**(측정형)로 설정.
> → 결과가 가설과 반대로 나와도(외국인도 회피) "회피 동선 지도"라는 산출물로 전환 가능 → 프로젝트 무산 위험 차단.

### 4.1 진단 모델 — 집단별 기상 탄력성
- **목표:** 폭염·미세먼지에 대한 집단별 반응 계수를 추정·비교.
- **종속:** 집단별 체류 편차(정규화값).
- **핵심 변수:** 체감온도·폭염더미(폭염축) / PM2.5(미세먼지축).
- **통제:** 요일·공휴일·월·성수기·시간대·행사·**강수**.
- **모델:**
  - 해석용: 선형/패널 고정효과 회귀(동·연도 고정효과로 트렌드 흡수).
  - 비선형·상호작용용: LightGBM + SHAP(임계·포화 효과 포착).
- **비교 포인트:** 내국인 모델 vs 외국인 모델의 기상변수 계수/SHAP. → 노출 격차의 통계적 입증.
- **상호작용(심화):** 동 유형(실내/실외) × 집단 × 기상 → "어떤 장소에서 외국인이 갇히는가".

### 4.2 ★ 교란 통제 (반드시)
- **계절·성수기:** 여름 관광객 증가가 폭염 아닌 휴가철일 수 있음 → 월·성수기·요일 더미 강하게, 또는 같은 주 내 좋은날 vs 나쁜날 within-group 비교.
- **다중공선성:** 체감온도·폭염더미·미세먼지·기온 상관 점검(VIF).
- **연도 효과:** 환율·한류 등 해마다 다른 관광 트렌드 → 연도 고정효과.

### 4.3 운영 모델 — 핫스팟 예측
- **목표:** 폭염/고농도 예보일, 동·시간대별 외국인 체류 예측 → 자원 배치 우선순위.
- **대상:** 진단에서 핫스팟으로 분류된 동.
- **피처:** 날짜·요일·공휴일·체감온도(예보)·미세먼지(예보)·행사.
- **모델:** LightGBM 회귀 또는 동별 시계열.
- **검증:** 시간 순 분할(과거→미래), 마지막 시즌 홀드아웃. 누수 방지(미래정보 금지).

### 4.4 산출물 종합
1. **폭염 취약 관광 핫스팟 지도** — 동·시간대 `기상강도 × 노출격차` 위험 스코어.
2. **무더위쉼터 미스매치 오버레이** — 쉼터 좌표 겹침 + 기상산업기술원 입지자료(거주민 기준)와 대조.
3. **운영 예측 스코어** — 예보일 동·시간대 외국인 밀집 예측.
4. (미세먼지 축) **폭염 vs 미세먼지 반응 대비 분석** — "회피 가능한 위협엔 반응, 지속·회피 어려운 위협엔 갇힘" 결론 검증.

## 6. 리스크 & 결정 필요 사항

- **결과 리스크:** 가설과 반대(외국인도 회피) → 측정형 연구 프레이밍으로 산출물 전환 가능(4장 참조). **무산 위험 없음.**
- **연도 선택:** 코로나기(2020~2021) 제외 필수, 2018 극단폭염은 넣을 시 별도 표기. → D-0에서 데이터로 확정.
- **미세먼지 축 포함 여부:** 포함 시 봄 시즌 추가 → FILE 다운로드량 2배. 작업량 vs 분석 풍부함 트레이드오프 → 팀 결정.
- **공간 단위:** 행정동 vs 집계구(세밀하나 `*` 결측 증가).
- **국적 분해:** 중국인/중국외 분리 분석 여부.
- **운영 모델 포함 여부:** 진단까지로도 완결 가능. 일정 따라 결정.
