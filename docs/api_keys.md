# 인증키 발급 안내

이 프로젝트는 **두 곳**의 인증키가 필요합니다. 둘 다 무료·개인 신청 가능.

---

## 1. 서울 열린데이터광장 (`SEOUL_OPEN_DATA_KEY`)

- 사이트: https://data.seoul.go.kr
- 용도: A-4 무더위쉼터, A-6 문화행사 (Open API)
- 절차:
  1. 회원가입(이메일 인증).
  2. 우측 상단 `마이페이지` → `인증키 신청/관리` → `인증키 신청`.
  3. 사용 목적 간단히 기재 → **즉시 발급** (보통).
  4. 발급된 키를 `.env` 의 `SEOUL_OPEN_DATA_KEY=` 에 붙여넣기.
- 호출 한도: 일 1,000회(데이터셋별 상이). 캐싱 필수.

## 2. 공공데이터포털 (`DATA_GO_KR_KEY`)

- 사이트: https://www.data.go.kr
- 용도: B-1 ASOS 종관기상관측, B-2 기상특보 이력, D-1 공휴일, (선택) C-1 에어코리아
- 절차:
  1. 회원가입.
  2. **데이터셋별로 활용신청** 필요 (한 번에 묶이지 않음).
  3. 사용할 데이터셋 페이지에서 `활용신청` → 사유 기재 → 신청.
     - 보통 **자동승인(즉시)** 이나, 일부는 1~2영업일 소요.
  4. `마이페이지` → `오픈API` → 발급된 **인증키(일반)** 복사.
     - "일반 인증키 (Encoding)" / "(Decoding)" 두 형태가 표시됨.
     - **URL 파라미터에 직접 넣을 때는 Decoding 키 사용**(urlencode 라이브러리가 알아서 인코딩하므로 이중인코딩 방지). → `.env` 에는 Decoding 키 권장.
  5. `.env` 의 `DATA_GO_KR_KEY=` 에 붙여넣기.

### 본 프로젝트가 신청해야 할 공공데이터포털 데이터셋

진행 순서대로 신청.

| 데이터셋명 | 제공기관 | 단계 | 비고 |
|---|---|---|---|
| (a) 지상(종관, ASOS) 시간자료 조회서비스 | 기상청 | **D-0 우선 + Phase 1 필수** | B-1, 체감온도·폭염일 모두 산출 |
| (b) ~~기상특보 조회서비스~~ | 기상청 | ~~사용 안 함~~ | **최근 7일만 조회 가능** — 과거 이력 수집 불가. 폭염일수는 ASOS 로 직접 계산 |
| (c) 한국천문연구원_특일 정보 | 한국천문연구원 | Phase 1 | D-1, 공휴일 |
| (d) 한국환경공단_에어코리아_대기오염정보 | 한국환경공단 | (PM축 결정 시) | C-1, 보류 중 |

> 데이터셋 정확한 명칭은 사이트에서 검색 시 미세하게 달라질 수 있음. "ASOS 시간자료", "기상특보 조회" 등으로 검색.

## 다 받으면

1. `cp .env.example .env`
2. `.env` 를 열어 두 키를 채워 넣기
3. 동작 확인:
   ```bash
   python -c "from src.config import require_key; print('OK' if require_key('DATA_GO_KR_KEY') and require_key('SEOUL_OPEN_DATA_KEY') else 'FAIL')"
   ```

---

## 주의

- `.env` 는 **절대 커밋·공유 금지** (`.gitignore` 로 제외됨).
- 키가 노출되면 즉시 사이트에서 재발급(이전 키 폐기).
- 호출 한도 초과 시 일시 차단될 수 있음 → 응답 캐싱 + `tenacity` 재시도로 방어.
